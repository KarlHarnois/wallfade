# wallfade

Fades the top and bottom edges of a wallpaper toward black.

## Usage

```
Fades the top and bottom edges of a wallpaper toward black.

Usage: wallfade [OPTIONS] <INPUT>

Arguments:
  <INPUT>              The wallpaper to fade

Options:
  -o, --output <PATH>  Where to write the faded wallpaper
  -h, --help           Print help
  -V, --version        Print version
```
